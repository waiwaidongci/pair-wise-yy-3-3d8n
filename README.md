# 岩芯样本切片实验室

运行：

```bash
npm start
```

访问 `http://localhost:3025`。支持样本创建、切片任务、步骤记录和交付统计。

## 分样与外送台账

入口：首页右上「分样与外送台账 →」或直接访问 `http://localhost:3025/ledger`。

业务规则：

- **母样余料**：先登记余料（数量+单位），每次登记/更正写入余料变更史。
- **分样**：写明编号、深度区间、数量、用途；自动核验并展示本笔后余量。
- **冲突处理（保留原记录并说明）**：
  - 区间重叠（与同母样其他分样深度相交）
  - 超出余料（按已外送先扣、在库分样按创建顺序累计核定）
  - 编号重复（记录共存，不覆盖旧记录）
  - 深度超出母样区间属于录入错误，直接拒绝（400）
- **外送冻结**：分样外送后冻结，不可再改或重复外送（409），冻结时留存余料快照。
- **回执**：回执写明检测项目和结论；首份回执自动归档，之后的迟到回执只追加并标记，**不能改掉已归档结论**。
- **余料更正**：未外送分样自动重算区间/余料冲突；已外送分样保留旧档，若更正改变了其外送时的余料，则标出「受余料更正影响」。

### 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/ledger/samples` | 台账视图（旧数据自动补齐字段） |
| POST | `/api/ledger/samples/:id/remainder` | 登记/更正母样余料，触发重算与影响标记 |
| POST | `/api/ledger/samples/:id/splits` | 新增分样（冲突保留并说明） |
| PATCH | `/api/ledger/samples/:id/splits/:sid` | 更正未外送分样（已外送 409） |
| POST | `/api/ledger/samples/:id/splits/:sid/dispatch` | 登记外送并冻结 |
| POST | `/api/ledger/samples/:id/splits/:sid/receipts` | 登记回执（迟到不改归档） |

### 代码分层

- `store.js` — **保存**：JSON 文件持久化，写操作经 `transaction` 串行化读改写。
- `ledger.js` — **区间核验与台账规则**：纯领域逻辑（深度解析/重叠判定/余料核定/冻结/归档/重算），无 IO。
- `server.js` — **接口**：HTTP 路由与参数解析，只做编排。
